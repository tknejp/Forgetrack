Fitness tracker focused on Health Connect data, nutrition logging, and Google Sheets sync.

## Branding Assets

Project branding lives in `assets/branding/`:
- `app-icon.png` for launcher and compact brand-mark usage
- `wordmark-dark.svg` for light backgrounds
- `wordmark-light.svg` for dark backgrounds
- `wordmark-gradient.svg` for README and marketing placements

Platform icon derivatives are generated by:
- `tooling/generate_branding_assets.ps1`

## Getting Started

1. Install Flutter.
2. Run `flutter pub get`.
3. Start the app with `flutter run`.

## Development Notes

- App strings and visual branding are centralized for easier future updates.
- If the logo changes, regenerate platform assets before shipping a release.
