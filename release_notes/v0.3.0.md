# Forgetrack v0.3.0 — release notes pro testery

Větší build: appka se od teď umí **aktualizovat sama**, Social se přejmenoval na **Fellowship** a dostal novou horní lištu s vyhledáváním a notifikacemi.

## Co je nového

### 🔄 Aktualizace přímo v appce (novinka)
- Forgetrack se teď updatuje sám. Když vyjde nový build, přijde ti push a po otevření appky se nabídne **„Stáhnout a nainstalovat"** rovnou v dialogu — žádné posílání APK přes Signal.
- **Tohle je první build s touhle funkcí.** Tenhle jeden ještě nainstaluj ručně (ze zaslaného odkazu); od příště to bude jedno ťuknutí.

### 👥 Fellowship (dřív Social)
- **Social → Fellowship** a **Feed → Chronicle** — sjednocené názvosloví.
- Nová **horní lišta s trvalým vyhledáváním a zvonečkem** notifikací.
- **Reakce a žádosti o přátelství** sloučeny do jednoho panelu pod zvonečkem.
- Ke sdílení do Chronicle můžeš přidat **vlastní zprávu**; větší orámovaný avatar autora.

### 🛠 Opravy
- **Onboarding:** welcome pack se předvybaví a oslavy se dorovnají ještě před vstupem do appky (žádné ztracené uvítací eventy).
- **Fellowship:** vyhledávací panel jde zavřít swipem dolů i když je seznam dlouhý.
- **Fellowship:** emblémové sloty se na úzkých displejích nepřetékají.
- **Fellowship:** opraveny žádosti o přátelství po odblokování + avatar cizího profilu.

## Co testovat prioritně

1. **Fellowship horní lišta** — vyhledávání, zvoneček, nové bottom sheety (reakce + žádosti).
2. **Sdílení do Chronicle** se zprávou + jak vypadá ve výsledném záznamu.
3. **Onboarding nového účtu** — odhlas/přihlas (nebo přeinstaluj) a sleduj uvítací sekvenci.
4. **In-app updater** — po instalaci tohoto buildu počkej na další release a ověř, že přijde push + dialog „Nová verze".

## Známé problémy

- Žádné release-blockery k tomuto buildu.
- První instalace tohoto buildu je ruční (sideload) — předchozí verze ještě in-app updater neměla.

## Reset / migrace dat?

- **Ne.** Žádné DB schema změny ani Firestore wipe — update přes 0.2.1 funguje normálně.
